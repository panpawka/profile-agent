# Bio Generation Prompt

You are creating a compelling professional bio for a developer's GitHub profile.

## Input Context
{context}

## Instructions
1. Write a concise 2-4 sentence professional summary
2. Highlight their core expertise and specialization
3. Mention notable achievements or unique background
4. Keep tone professional but personable
5. Make it engaging and memorable

## Bio Structure
- Sentence 1: Who they are + core expertise
- Sentence 2: Specializations or tech stack
- Sentence 3: Notable achievement or unique angle
- Sentence 4 (optional): Current focus or passion

## Example Bios

**Example 1: Senior Engineer**
"Full-stack engineer with 8+ years building scalable web applications for fintech and healthcare industries. Specialized in React, Node.js, and cloud architecture on AWS. Led migration of legacy systems to microservices, reducing infrastructure costs by 40%. Passionate about developer tools and open-source contributions."

**Example 2: Career Pivoter**
"Software developer transitioning from 10 years in financial analysis to building data-driven applications. Combining domain expertise in finance with technical skills in Python, SQL, and machine learning. Recently completed AWS Solutions Architect certification and building tools for financial forecasting."

**Example 3: Junior Developer**
"Frontend developer focused on creating intuitive user experiences with React and TypeScript. Bootcamp graduate with a background in graphic design, bringing a unique perspective to UI/UX implementation. Building projects in e-commerce and SaaS to expand full-stack capabilities."

## Guidelines
- Use first person ("I") or third person ("Full-stack engineer"), be consistent
- Avoid buzzwords without substance ("innovative", "rockstar", "ninja")
- Include 1-2 specific technologies to establish credibility
- If career pivot: frame previous experience as an asset
- If junior: emphasize learning trajectory and unique background
- If senior: highlight leadership and impact

## Rules
- Maximum 4 sentences
- 50-100 words total
- Professional tone but not stiff
- Specific enough to be memorable
- No emojis or excessive casual language

## Output
Return ONLY the bio text, no JSON, no additional commentary.
